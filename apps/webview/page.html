This is a separate document

It is served from apps/webview/page.html and hosted in an iframe inside a webxp window. It knows nothing about the window manager, and the window manager knows nothing about it beyond its URL.

The serif type and warm background are this page's own, not the Luna theme. The first click raises the window; the next reaches the page.

Drag the title bar and the window still moves, because the pointer is lifted off the window body for the duration of a drag.
